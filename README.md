# 스마트 주문관리 & 발송처리 시스템 (OMS / WMS)

## 업체 계정 및 Render 배포 설정

- `/login`에서 업체 대표 계정을 만들거나 초대 코드로 직원 계정을 추가합니다. 한 업체의 사용자는 같은 주문·재고 데이터를 함께 사용합니다.
- `/admin`은 `ADMIN_USERNAME`, `ADMIN_PASSWORD` 환경 변수로 로그인하는 운영자 전용 화면입니다. 업체별 주문 건수와 발송 현황을 확인할 수 있습니다.
- 기존 DB 주문·재고 데이터는 자동으로 `젬마 (기존 데이터)` 업체에 귀속됩니다. 해당 데이터를 쓸 대표 계정을 만들려면 `LEGACY_OWNER_USERNAME`, `LEGACY_OWNER_PASSWORD`를 배포 환경에 입력한 뒤 앱을 재시작합니다. 비밀번호는 10자 이상으로 설정하세요.
- Render 환경 변수에는 기존 Supabase `DATABASE_URL`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `LEGACY_OWNER_USERNAME`, `LEGACY_OWNER_PASSWORD`, `NARDA_CUSTOMER_CODE`, `NARDA_API_KEY`, `NARDA_ID`를 설정해야 합니다. `FLASK_SECRET_KEY`는 Render에서 생성하고 `SESSION_COOKIE_SECURE=1`을 유지합니다.
- `DATABASE_URL`이 설정되어 있는데 PostgreSQL 연결이 실패하면 앱은 SQLite로 몰래 전환하지 않고 오류를 표시합니다. Render의 임시 파일 시스템에 주문 데이터가 저장되는 상황을 막기 위한 동작입니다.
- Narda 자격 증명은 코드나 저장소에 넣지 말고 Render 환경 변수 또는 업체 설정 화면에서 관리하세요. 이미 공개 저장소에 올라간 DB/API 비밀번호와 키는 코드에서 제거한 뒤 각각 새 값으로 교체해야 합니다.

저장소 업데이트만으로 `narda.onrender.com` 주소가 자동 변경되지는 않습니다. Render 서비스 이름/도메인 설정에서 주소를 변경하고, 해당 주소가 사용 가능해야 합니다.

엑셀 주문 파일을 업로드하면 **세트/복합 상품 자동 분할**, **재고 입출고 관리**, **택배사 API 송장 발급 및 라벨 인쇄**를 한 번에 처리할 수 있는 올인원 발송 관리 웹 시스템입니다.

## 🌟 주요 핵심 기능

1. **엑셀 주문 자동 업로드 및 지능형 분할 (Order Split Engine)**
   - 발송 리스트 엑셀 파일(`.xlsx`, `.xls`)을 드래그 앤 드롭으로 업로드
   - `LIGHT (외출전용 스틱) + PEARL (밤 전용)` 처럼 **`+` 기호로 묶인 옵션은 개별 단품 SKU로 자동 분할**
   - 1명이 여러 개 상품을 구매한 경우 품목별 행 분할 및 출고 수량 자동 계산
   - 업로드 즉시 원본 대비 분할 품목 결과를 미리보고 DB에 안전하게 등록

2. **실시간 상품 및 재고 관리 (WMS)**
   - 상품 및 단품 SKU 마스터 관리 (창고 위치, 안전재고, 현재고)
   - 주문 발송('출고완료') 처리 시 **재고 자동 차감**
   - 수동 입고(Stock-In) 및 재고 실사 조정 기능
   - 모든 입출고 내역이 투명하게 기록되는 **재고 변동 이력(로그)**

3. **택배사 연동 송장 발급 & 표준 운송장 인쇄 (Shipping & Labels)**
   - CJ대한통운, 우체국, 한진, 롯데, 로젠 등 택배사 선택 지원
   - 택배사 API 연동 및 표준 운송장 번호 자동 채번 (시뮬레이션 모의 발급 모드 기본 탑재)
   - **표준 택배 운송장 라벨 출력**: 100x150mm 송장 라벨 규격 및 A4 출력 지원 (Code128 바코드 실시간 렌더링)
   - 스마트스토어/쿠팡 일괄 업로드용 **송장완료 엑셀 다운로드**

4. **사용자 맞춤형 분할 규칙 설정 (Bundle Rules)**
   - 특정 옵션명(예: 세트 구성, 1+1, 4개입 등)에 대해 원하는 품목과 배수로 쪼갤 수 있는 커스텀 분할 룰 등록

## 🚀 빠른 시작 방법 (실행 방법)

### 방법 1. 더블 클릭으로 바로 실행 (가장 쉬움)
폴더 안의 **`run.bat`** 파일을 더블 클릭하면 웹 서버가 실행되고 브라우저가 자동으로 열립니다.

### 방법 2. 터미널 명령어로 실행
```bash
python app.py
```
실행 후 브라우저에서 아래 주소로 접속하세요:
👉 **http://localhost:5050**

## 📂 프로젝트 파일 구조

- `app.py`: Flask 백엔드 서버 및 REST API
- `database.py`: SQLite 데이터베이스 스키마 및 DB 관리 (`orders.db`)
- `excel_processor.py`: 엑셀 파싱, 헤더 자동 매핑, 주문/옵션 분할 처리 엔진
- `shipping_api.py`: 택배사 송장번호 발급, 출고 재고 차감, 송장 엑셀 내보내기
- `templates/index.html`: 반응형 모던 대시보드 UI (주문관리, 송장인쇄, 재고관리, 설정)
- `run.bat`: 윈도우 원클릭 실행 배치 파일
- `orders.db`: 주문, 품목, 재고, 로그가 저장되는 SQLite 데이터베이스
